# Week 1 Internship Task Report

## Objective

The objective of this task was to convert a wireframe concept into a responsive static webpage using HTML and CSS.

## Technologies Used

* HTML5
* CSS3
* Visual Studio Code

## Features

* Responsive navigation bar
* Hero section
* About section
* Services cards
* Contact section
* Footer
* Smooth scrolling navigation
* Responsive design using media queries

## Design Decisions

Semantic HTML tags were used for better structure and readability. CSS Flexbox was implemented to align elements and create responsive layouts.

A modern color gradient was used in the hero section to improve visual appearance. Hover effects and transitions were added for better user interaction.

## Responsiveness

Media queries were used to ensure the webpage works properly on mobile devices, tablets, and desktops.

## Challenges Faced

One challenge was maintaining responsiveness across different screen sizes. This was solved using Flexbox and CSS media queries.

Another challenge was organizing the navigation layout for mobile screens, which was handled by stacking navigation links vertically on smaller devices.

## Conclusion

This task improved my understanding of webpage structure, responsive design, semantic HTML, and CSS styling techniques.
